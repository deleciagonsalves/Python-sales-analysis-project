# Sales & Inflation Analysis with Python

A beginner data-analysis project using Pandas. It cleans a sample sales dataset, finds trends, and adjusts sales for inflation to show the difference between nominal and real growth.

## Skills shown
Data cleaning (handling missing values), groupby analysis, growth rates, data visualisation, nominal vs real values (economics)

## Tech stack
Python, Pandas, NumPy, Matplotlib, Google Colab

## Data
Simulated monthly sales for 4 product categories (Jan 2024 to Dec 2025), generated in the notebook. Not real company data. Inflation is assumed at 5% per year.

## How to run
Open `Python_Sales_Inflation_Analysis.ipynb` in Google Colab and click Runtime > Run all.

## Future improvements
Use real CPI data from MoSPI, and real sales or retail data.
